ℹ️ ABOUT APPVERSE ARnc

About this website

Welcome to AppVerse ARnc

AppVerse ARnc is a personal, local-first launcher designed to help you keep useful websites, web applications, HTML projects, games, and Android APK installer files together in one convenient library. Instead of searching through bookmarks, downloads, and scattered files every time you want to open something, you can create a single collection that is easy to browse and search.

The website provides a simple way to add a shortcut for a website, save an HTML application by pasting its code or choosing an HTML file, and keep an Android APK installer available for download. You can give an item a display name and optionally choose an image for its icon. The library grid shows each item as a tile, making your collection easier to recognize at a glance.

Website shortcuts: Add a full website address beginning with https:// or http://. When you open that tile, AppVerse ARnc attempts to open the address in a new browser tab. It may try to display the website’s favicon automatically, although some websites do not expose an icon or restrict access to it. A custom icon can be used when you want a more recognizable tile.

HTML applications: You can paste complete HTML code or select an .html or .htm file. The app opens HTML content in its built-in preview frame, which uses browser sandbox restrictions. These restrictions help limit what previewed content can do. Some projects depend on separate images, scripts, fonts, files, server routes, or permissions that are not included in the HTML itself; such projects may need those resources embedded or otherwise made available before they work correctly in a preview.

Android APK files: AppVerse ARnc can keep an APK installer in its local library and offer it for download. A normal browser cannot run or install an Android APK directly on a computer. To use the installer, download it and transfer or open it on a compatible Android device, then follow Android’s installation prompts and security settings. Only install APK files from sources you trust.

Search and categories: Use the search field to find saved items by their name, type, or website address. Category filters help narrow the library to relevant items. Quick Actions at the top of the page provide direct access to common tasks, including adding a website, adding an HTML app, adding an APK, and exporting a library list.

Renaming and deleting: Library tiles open the saved item when clicked. This version does not include a per-item options menu for renaming or deleting entries. Consider exporting a backup list before making major changes. The export is a JSON description of the saved item list; it does not include the contents of locally stored files, so it should not be treated as a complete backup of HTML or APK file data.

How storage works: The site uses browser storage, including IndexedDB when available, to save library entries on the current browser and device. This approach avoids requiring an AppVerse account or a remote application database for ordinary library use. Browser storage availability and limits vary by browser and device. Private browsing modes, storage restrictions, browser cleanup tools, or clearing site data may prevent information from persisting or may remove saved entries.

What to expect: AppVerse ARnc is a launcher and organizer, not an app store, APK installer, hosting service, antivirus scanner, or guarantee that every external website or HTML project will work. External websites can change or become unavailable. The website cannot guarantee the safety, legality, compatibility, or performance of files and links you choose to add. You remain responsible for the content you save and open.

We recommend using descriptive names, choosing trusted sources, and keeping separate backups of important original files. Test HTML projects in a safe environment and verify that external links are correct before opening them. If browser storage is unavailable or full, the library may not save changes reliably; free space or use a supported browser and check that site data is permitted.

Our goal is to keep the interface straightforward: add the things you use, find them quickly, and open them from one place. The existing library, filters, item tiles, add-item dialog, HTML preview, APK download, rename/delete menu, and JSON export remain the primary tools of the website.

🔒 PRIVACY POLICY

Privacy and data handling

Your privacy matters

This Privacy Policy explains how AppVerse ARnc handles information when you use this website. The current version is designed as a local-first launcher: library information is saved in browser storage on the device and browser you are using. No account is required for the core library features, and the supplied website code does not intentionally send your library database to an AppVerse remote server.

Information you choose to enter: When you add an item, you may provide a display name, website URL, HTML code, an HTML file, an APK file, and an optional custom icon. These details are used to create the library entry and support the functions you request. They may remain in the browser’s local storage so the entry can be displayed after you revisit the page.

Local browser storage: The app uses IndexedDB where available to store library records and file data. This data is associated with the browser’s site storage on your device. People who can access your browser profile or device may be able to access that stored data. Local storage is not the same as encrypted cloud storage, and the site does not promise that locally saved information is encrypted or protected from other users of the same device.

Website links and external services: When you open a website shortcut, your browser connects to the destination website. That website may receive standard connection information such as your IP address, browser details, and any information you submit there, according to its own policies. AppVerse ARnc does not control third-party websites and is not responsible for their privacy practices. Review their policies before sharing personal information.

Icons and remote requests: For a website shortcut, the page may attempt to load a favicon from the website’s domain. This can cause a request to that domain, which may receive ordinary network information. If you upload a custom icon, it is used for the library tile in the browser. The supplied code does not intentionally upload that custom icon to an AppVerse server.

HTML preview: HTML content that you add is displayed in a sandboxed iframe with scripts, forms, and modals permitted. Sandbox settings are a protective browser feature, but they are not a guarantee that all content is risk-free. A project may itself request remote resources or navigate to external services. Only preview code and files from sources you trust, and inspect the content if you are unsure what it does.

APK files: APK installers you add are stored locally when browser storage permits. The app provides a download action; it does not scan APKs for malware. If you download or install an APK, the destination browser, operating system, security software, or app may process it under its own rules. Do not install files from unknown or suspicious sources.

Exporting: The Export library action downloads a JSON file containing the library’s item descriptions. For privacy and size reasons, the export excludes the actual locally stored file contents. The exported JSON may still include names, URLs, and other item details, so treat it as personal data: save it in a safe place and do not share it publicly unless you intend to disclose its contents.

Data sharing and sale: Based on the supplied website code, the app does not include an AppVerse account system, advertising tracker, analytics integration, or application backend that deliberately sends the library contents to a central service. This statement describes the code provided for this version and cannot cover changes made by a host, browser extensions, network provider, or external websites you open. No claim is made about third-party infrastructure outside the site’s control.

Retention and deletion: Your library data generally remains in browser storage until you delete individual entries, clear the site’s browser data, or the browser removes storage under its own policies. This version does not include a per-item delete menu. Clearing browser storage may remove many or all entries at once and may not be reversible. Exporting the item list before clearing storage can preserve a limited record, but does not back up file contents.

Children and sensitive information: AppVerse ARnc is a general-purpose launcher, not a service designed to collect sensitive personal information. Avoid storing passwords, payment details, identity documents, private health information, or other highly sensitive data in item names, URLs, HTML content, or files. If children use the same device, use appropriate device-level accounts and access controls.

Security: Keep your browser and operating system updated, use a device passcode, and avoid shared or public devices for private libraries. Local-first storage reduces the need to transmit library data to a central server, but it does not remove risks from malware, compromised devices, malicious HTML, unsafe downloads, or people with access to your browser profile. You are responsible for deciding which links and files to save and open.

Your choices: You can choose what to add, use custom names, delete entries, export a list, or stop using the website. You can also use your browser’s site-data settings to clear stored information. Before deleting site data, remember that this can remove your library. If you host or modify this website, review any additional scripts, hosting features, analytics, advertising, or third-party services you add, and update this policy to accurately describe them.

Policy changes and contact: This policy may need to change if the website’s features, hosting, or data practices change. The website code supplied here does not provide a verified privacy contact address, so none is listed. If you publish this website for other people, add an appropriate contact method and confirm that the policy matches your actual hosting and applicable legal requirements before relying on it as a formal legal document.

By using AppVerse ARnc, you understand that the library is intended to operate locally in your browser and that opening external links or using content you add may involve other services. This policy is a practical description of the supplied code, not legal advice or a guarantee of absolute security.
